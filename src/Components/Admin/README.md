# صفحات إدارة الصفحة الرئيسية

## الصفحات الجديدة المضافة:

### 1. صفحة إدارة صور السليدر

- **المسار**: `/admin/slider-images`
- **الوصف**: إدارة صور السليدر التي تظهر في أعلى الصفحة الرئيسية
- **المميزات**:
  - إضافة صور سليدر جديدة
  - تعديل الصور الموجودة
  - حذف الصور
  - تحديد ترتيب العرض
  - تفعيل/إلغاء تفعيل الصور
  - معاينة الصور قبل الحفظ

### 2. صفحة إدارة صور قسم الخصم

- **المسار**: `/admin/discount-images`
- **الوصف**: إدارة صور قسم الخصم التي تظهر تحت السليدر مباشرة
- **المميزات**:
  - إضافة صور خصم جديدة
  - تعديل الصور الموجودة
  - حذف الصور
  - تحديد ترتيب العرض
  - تفعيل/إلغاء تفعيل الصور
  - معاينة الصور قبل الحفظ

## كيفية الوصول:

1. سجل دخولك كمدير
2. اذهب إلى الشريط الجانبي للإدارة
3. اختر "صور السليدر" أو "صور قسم الخصم"
4. ابدأ بإدارة الصور

## مواصفات الصور:

- **صور السليدر**: 800x400 بكسل (مثالية)
- **صور قسم الخصم**: 600x300 بكسل (مثالية)
- **الصيغ المدعومة**: JPG, PNG, GIF
- **الحد الأقصى**: 5MB لكل صورة

## ملاحظات مهمة:

- الصور يتم تحسينها تلقائياً عند الرفع
- يمكن ترتيب الصور حسب الأولوية
- الصور غير النشطة لن تظهر في الموقع
- جميع التغييرات تظهر فوراً في الموقع
